# Welcome to Our E-Commerce Project, My Guy!

We're building a fantastic React + Vite e-commerce application here, with a Supabase backend that's the real deal! It's got real-time sync, an admin dashboard, and all the features for a great user experience. And, of course, it's all about selling high-end gadgets, like phones, laptops, and whatnot.

## The Tech Stack, Abi?

We're using the following tech to make this project tick:
* React 19 (the latest and greatest, no cap)
* Vite 5 (for blazing fast development, my guy)
* React Router 7 (for navigation that's easy peasy)
* Supabase (for the backend, with PostgreSQL, Auth, Realtime, and Storage)
* CSS Variables, CSS Modules, Framer Motion, and GSAP (for styling that's fire)
* Recharts (for charts and graphs, no doubt)
* React Quill and React Helmet Async (for forms and SEO, you feel me?)
* EmailJS (for sending emails, like a boss)
* Lucide React (for icons that are cool, no cap)

## Features, You Ask? Well, My Guy...

We've got all sorts of features to make this e-commerce project a real banger:
* Home page with a hero carousel, feed carousel, and product recommendations that are on point
